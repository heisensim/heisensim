Why heisensim?

🔍

Auto-discovery

Zero configuration needed. Automatically discovers pods, services, and probes in your namespace to target for testing.

📐

Property Checking

Define SLA properties (e.g. recovery time < 30s, availability > 99%) and automatically verify them against fault scenarios.

⏪

Deterministic Replay

Tests run with a specific seed. Found a bug? Replay the exact same sequence of faults locally or in CI.

📊

OTel Correlation

Integrates with OpenTelemetry to correlate injected faults directly with your application traces and metrics.

🎮

Explore Mode

Interactive TUI to manually trigger faults and watch system behavior in real-time before automating.
